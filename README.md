# 好好吃

静态 PWA，无账号、云数据库、Sites R2 或同步钥匙。收藏与压缩后的照片保存在当前设备、当前浏览器和当前网站地址对应的 IndexedDB 中；不会自动跨设备同步。清除 Safari 网站数据会删除本机收藏，请定期使用设置中的「导出完整备份（含照片）」。备份文件由用户自行保管。

部署时应用源代码将放在公开 GitHub Pages 仓库中；仓库不包含用户收藏或照片。应用数据仅存在于每位用户自己的设备中，不会发送到托管平台。

## 构建和检查

- `npm run build` 生成可直接部署的静态文件到 `dist/`。
- `npm test` 运行协议和静态部署安全检查。
- `python3 -m unittest discover -s tests -v` 运行浏览器端表单、搜索、编辑、照片持久化、删除和备份恢复检查（需要 Python Playwright 与 Chromium）。
